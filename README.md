# learn-ai-agent 🚀

> 我的 AI Agent 自学仓库（大一上学期）
> 起点：零基础 + 同时学 C 语言，每天约 3 小时
> 目标：独立开发接入大模型的微信小程序

## 📌 学习方法（五步法）
1. **先会工具**：Codex / Claude Code 是第一基础
2. **拒绝幻想式学习**：让 AI 教，更要让 AI 审计，杜绝"假装学会"
3. **脚手架思维**：每阶段先 websearch 出计划，做完一个打磨一个
4. **训练场**：以 awesome-llm-apps 为教材，复刻代码
5. **面试题驱动**：用最新面试题和技术更新学习重点
